# English v1: machine draft

English v1 adds machine-translated names for 51 entities/characters, five
facilities, 15 levels, 22 missions and 100 areas to the existing English menu
pack. It now also includes 207 monkey names from the capture/collection records.
All 400 gameplay labels are marked `draft`, with `origin=machine_translation`,
in `english-gameplay-v1.json` (in the separate [`sarusaru-translations`](https://github.com/jackgllghr/sarusaru-translations) repository).
These provisional translations were generated by the coding assistant; they
are not official localized names or human-reviewed terminology.

With the expanded UI catalog, the pack contains 467 strings and
242 image labels across 38 textures,
four Options help lines and the supplied English logo. Unresolved binary
candidates are excluded. Custom message streams, other image text, movies and
voice remain Japanese. This is a first label translation, not a complete game
translation.

## Build and run

After normal game preparation and installing the existing translation tool
requirements, run from the repository root:

```sh
out/translation-tools/bin/python profiles/sarusaru/tools/build_menu_translation.py \
  '/path/to/SaruSaru.iso' \
  --gameplay-catalog ../sarusaru-translations/english-gameplay-v1.json \
  --output out/translations/english-v1.sstp
python3 profiles/sarusaru/scripts/build_and_run.py -- \
  --translation-pack out/translations/english-v1.sstp
```

Use the rebuilt executable: the full gameplay catalog now uses `SSTEXPK5`
with HD image lettering and 201 compact capture/collection name lookups. Existing V1-V4 packs still
load in the updated runtime; omitting `--gameplay-catalog` still builds the
menu-only pack. Persist selection with `[translation]`, `language = en` and
`pack = /absolute/path/to/english-v1.sstp` in your settings. `language = ja`
restores Japanese.

The new format retains V2's record layout but permits a source string followed
by zero padding inside a declared name field. The gameplay builder uses only
the known 128-byte name fields for expansion. It hashes the entire field and
rejects nonzero padding, overlaps and overflow. Runtime validation checks every
source before writing any replacement. Table IDs, pointers and trailing metadata
retain their original values. Packed area strings keep their original capacity.

`text` contains a full natural draft. For area labels exceeding the byte budget,
`runtime_text` supplies an explicit shorter wording. Building does not truncate
words or invent abbreviations. Both versions need human review. New labels must
fit one line and 44 columns; their actual placement on every gameplay screen
still needs visual review.

## Human translation later

`extract_translation_labels.py export` now seeds handoffs with machine drafts
and review notes. Existing translator edits and notes take precedence on
re-export. Follow the [handoff guide](translation-handoff.md) to edit `labels.csv`.
The 21 ambiguous area-level associations remain flagged even though their visible
names now have draft translations.

Import a returned CSV handoff into a separate English-only catalog:

```sh
python3 profiles/sarusaru/tools/extract_translation_labels.py validate /path/to/handoff
python3 profiles/sarusaru/tools/extract_translation_labels.py import-drafts /path/to/handoff \
  --output out/translations/english-human-draft.json
out/translation-tools/bin/python profiles/sarusaru/tools/build_menu_translation.py \
  '/path/to/SaruSaru.iso' \
  --gameplay-catalog out/translations/english-human-draft.json \
  --output out/translations/english-human.sstp
```

Import preserves source hashes and review status. Changed wording or reviewed
entries are marked as human translation. When full wording changes, the obsolete
runtime abbreviation is removed. Add a new `runtime_text` to the imported
catalog if the builder reports an area byte overflow. An intentionally empty
CSV translation omits that label and restores Japanese. This importer covers
the 400 gameplay labels; menu authoring remains in `english-menu.json`.

## Verification and remaining work

Tests cover padded-field replacement, nonzero-padding rejection, unchanged V2
restrictions, source/placeholder checks, preserved human edits and removal of
stale abbreviations. A local test against the supported executable applied all
232 strings, checked all 193 gameplay replacements and confirmed every
neighboring `.rodata` byte remained intact. The combined pack also passes a
native startup smoke check.

Individual gameplay screens, progression-dependent content and terminology
are not all visually verified. Human review should check names, puns, context,
short versions and placement before calling this a finished translation.
Translation tools never write the ISO, prepared executable or original saves.
Generated packs and extracted Japanese source text remain local and ignored.

atlases, compact-name lookup matching, updated runtime limits and verification.
